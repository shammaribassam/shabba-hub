# بنك أسئلة سين وجيم أبو البسم

الهدف المعتمد: **2,000 سؤال مختلف في كل فئة من الفئات الأربع عشرة (28,000 سؤال)**. هذا **هدف** وليس عددًا مكتملًا. التطبيق يعرض الأعداد الفعلية لكل فئة ولا يختلق أسئلة.

## إضافة دفعة جديدة

أضف ملفًا باسم مختلف داخل هذا المجلد، مثل `football-batch-002.json`. صيغة الملف:

```json
{
  "category": "football",
  "questions": [
    {
      "question": "ما اسم المنتخب الفائز بكأس العالم 1998؟",
      "answer": "فرنسا",
      "value": 200
    }
  ]
}
```

القيم المسموحة: `200` سهل، `400` متوسط، `600` صعب. يجب أن تكون الأسئلة دقيقة، ذات إجابة واضحة، متنوعة، ومراجَعة بشريًا قبل إضافتها. لا تنسخ نصوص قواعد بيانات غير مرخصة، ولا تضف نسخًا معاد صياغتها من السؤال نفسه لتضخيم العدد.

المحرك يفحص الحقول المطلوبة، المستوى، تكرار نص السؤال داخل الفئة، والحد الأقصى (2,000 سؤال). تظهر الإجابات للمقدم فقط إلى أن يكشفها. اختيارات المباريات تتجنب تكرار السؤال في الغرفة نفسها إلى أن تنفد أسئلة المستوى.

بعد إضافة دفعة نفّذ `npm run check`. سيُوقف الخادم تحميل البنك إذا كان الملف غير صالح أو يحتوي تكرارًا، حمايةً لجودة الأسئلة.

الفئات المعتمدة: football, gaming, anime, geography, history, science, cinema, series, wrestling, islamic, technology, literature, saudi, cars.

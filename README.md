# شبّة أبو البسم — الموقع الموحّد

مستودع مستقل يجمع الديوان الشعري وتحديات أبو البسم تحت رابط واحد. نسختا GitHub الأصليتان وخدمتا Render القديمتان لا تتغيران.

بعد رفع هذه الملفات، ينسخ GitHub Actions مشروعي:
- `shammaribassam/diwan-abu-albasm` → `games/diwan`
- `shammaribassam/shabba-abu-albasm` → `games/quiz`

وذلك يشمل أسئلة الديوان والتحديات والصور والأصوات.

## التشغيل على Render
أنشئ **Web Service** جديدًا واختَر هذا المستودع والفرع `main`.
Build Command: `npm install`، Start Command: `npm start`.
لا تعدل خدمات Render القديمة.

المسارات:
- `/`: صفحة اختيار المجلس.
- `/diwan/streamer.html` و `/diwan/viewer.html`: الديوان.
- `/quiz/streamer.html` و `/quiz/viewer.html`: التحديات.

أثناء النشر، قد تحتاج إعادة إعداد متغيرات البيئة وربط Kick webhook للدومين الجديد. لا تضع Client Secret في المستودع. يجب تجربة ربط Twitch وKick وTikTok بعد النشر.

## 🎮 ألعاب أبو البسم — ربط الشات داخل الموقع الرئيسي

- رابط الألعاب: `https://shabba-hub.onrender.com/arcade.html`.
- المقدم يختار لعبة، ينشئ غرفة، ينسخ رابط اللاعبين أو شاشة OBS، ويبدأ اللعب بعد انضمام لاعبين على الأقل.
- داخل الغرفة، افتح **ربط الشات** واكتب اسم القناة واضغط «ربط» لكل منصة على حدة. ستظهر حالة فعلية: جارٍ الاتصال، متصل، بانتظار البث/الرسائل، أو خطأ.
- **Twitch:** قراءة رسائل الشات العامة عبر IRC دون تسجيل دخول أو صلاحيات إدارة؛ قد تحد المنصة من الاتصال ببعض القنوات.
- **Kick:** يستخدم التطبيق الرسمي `KICK_CLIENT_ID` و`KICK_CLIENT_SECRET` على Render، واشتراك `chat.message.sent`، والتحقق من توقيع RSA على `/api/kick/webhook`. يجب ضبط رابط Webhook في تطبيق Kick. إن رفضت Kick الاشتراك، سيظهر خطأ ولا تُعتبر القناة متصلة.
- **TikTok:** موصل `tiktok-live-connector` أثناء البث المباشر فقط، ويعيد المحاولة إذا كان البث غير متاح. الاتصال تجريبي وقد يتأثر بتغييرات المنصة.
- أوامر Twitch وKick: `!انضم`، `!طرد 5`، `!إنعاش 5`، `!سكيب`، `!باب 3`، `!نجاة`، `!مرر 5`، `!كرسي 2`، `!صندوق 4`. يقبل TikTok الأوامر بدون `!` أيضًا.
- المتابعون يستطيعون اللعب برابط الغرفة حتى إذا تعذر ربط أي منصة. لا تُخلط رسائل قنوات الستريمرز المختلفة.
- **مهم:** الغرف مؤقتة وموجودة في ذاكرة الخادم فقط؛ تنتهي بعد ست ساعات من عدم النشاط وتُفقد عند إعادة تشغيل الخدمة أو نشر نسخة جديدة. لا تُعتبر خدمة حفظ دائم.
- المشروع `bsm-chat` مستقل ومحفوظ دون تعديل أو اعتماد عليه في ألعاب الموقع.
- الاختبارات الآلية لمنطق اللعب لا تعادل تجربة بث حقيقي. يجب اختبار رسالة `!انضم` من كل منصة بعد بدء البث.

## 🧠 سين وجيم أبو البسم — تحدّي الفريقين

- صفحة اللعبة المستقلة: `https://shabba-hub.onrender.com/seen.html`، بعد قسم الألعاب وقبل **وضع المجلس** (يبقى آخر قسم في الصفحة).
- 14 فئة أصلية، **252 سؤالًا** (18 سؤالًا لكل فئة: 6 سهلة و6 متوسطة و6 صعبة). يختار المقدم 6 فئات، ثم تُسحب خانتان من كل مستوى بكل فئة لتكوين **36 سؤالًا**.
- الفريقان يتناوبان اختيار الخانات. لكل فريق قائد يختاره المقدم من المشاركين. أعضاء الفريق يتشاورون، **والقائد وحده** يرسل الإجابة النهائية عبر `!جواب نص الإجابة` في شات القناة المربوطة؛ لا توجد مسابقة سرعة بين المشاهدين.
- انضمام المشاهدين من Twitch وKick عبر `!انضم`. يمكن إضافة مشاركين يدويًا وتوزيعهم وتعيين القادة من لوحة المقدم. الاتصال يعتمد على صلاحية الوصول الفعلية للشات، وليس مضمونًا لكل قناة.
- المقدم يحكم على إجابة القائد ويمنح النقاط أو يفتح فرصة السرقة، ويستطيع تسجيل الإجابة الشفوية وتعديل النقاط وإيقاف الوقت وكشف الإجابة. كشف الإجابة يلغي فرصة السرقة منعًا للغش.
- المؤقت الافتراضي 60 ثانية، والسرقة 15 ثانية. اختيار الوقت من لوحة المقدم.
- مشاركة شاشة المتابعين من زر **نسخ رابط شاشة المتابعين**؛ رابط المشاهدة لا يحتوي رمز المقدم ولا يكشف الإجابة قبل إعلانها.
- صلاحية المقدم محفوظة في `sessionStorage` لذلك تبقى عند تحديث نفس التبويب، وقد تضيع عند إغلاقه. لا ترسل صفحة المقدم أو رمزها إلى غيرك.
- الغرف مؤقتة في ذاكرة الخادم وتنتهي بعد 6 ساعات من عدم النشاط، وتُفقد عند إعادة تشغيل Render أو نشر إصدار جديد.
- فحص آلي: `npm run check` ويشمل اختبارات خصوصية الإجابات والتناوب والسرقة والقادة والمؤقت.
